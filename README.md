# MBTI 成人评估 · 在线测评表

一个纯前端、零依赖的 MBTI 自助测评页面，基于迈尔斯-布里格斯类型指标（MBTI）的四维度偏好模型（E/I、S/N、T/F、J/P）设计。

## ✨ 功能特点

- **40 道测评题目**：覆盖四个维度的偏好判断
- **1–5 分评分**：从“完全不像我”到“非常像我”
- **自动计分**：汇总 E/I、S/N、T/F、J/P 各维度得分
- **即时结果**：自动判定四字母 MBTI 类型并展示对应描述
- **响应式设计**：兼容桌面端与移动端
- **零依赖**：纯 HTML + CSS + JavaScript，无需构建工具

## 🚀 使用方法

### 方式一：直接打开
下载 `index.html`，双击用浏览器打开即可使用。

### 方式二：快速测评
1. 不加思考，不需要想太多
2. 答案没有好坏，纯属个人偏好
3. 测评后截屏把结果发给我
